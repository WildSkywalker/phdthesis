\section{Current State of the Problem}
For the big picture, we aim to establish the convergence theorems for the
$t$-SNE algorithm with generalized input and output kernels. For convenience,
if not specified or otherwise explicitly defined, all notations are the same as
in \cite{auffinger-tsne}. At the currently state, we have shown that the
relative entropy $t$-SNE with generalized kernel $g$ converges and can be
computed if $g$ satisfies the following:

$g(y,y') \equiv k (\norm{y-y'})$ such that:

1. $k: \mathbb{R}^+ \to \mathbb{R}^+$ is decreasing and bounded.

2. $g$ satisfies
\begin{align}
    \iint_{(0,\infty)^2} g(x,x') dxdx' < \infty.
\end{align}

3. $k$ has bounded derivative.

4. $k'(0) = 0$.

More importantly, the good news is that the proofs concerned with generalized
output kernel does not interfere with the input kernel. This significantly
reduces the complexity and potential roadblocks for us to continue working on
the generalized input kernel.

There are two main steps before we can complete the project. On one hand, we
need to give a specific form to the generalized input kernel, then prove the
existence and uniqueness of $\sigma^*$, because without the constraint on
perplexity, $t$-SNE will fail. On the other hand, we need to prove the bounds
for approximation and produce similar results like those in
\cite{auffinger-tsne}. This document is dedicated to the former, and serves as
the second main step in this project, hence the name.
\section{The Generalized Input Kernel}
The most important question that sets the foundation of the problem is, what
does the output kernel look like, given two data points $x$, $x'$ and parameter
$\sigma_i$. We can start by assuming that the input kernel only depends on
$\norm{x-x'}$ because $t$-SNE is about the relationship of data points to each
other. Then, we may further assume that the input kernel is the function of
$\sigma \norm{x-x'}^{\theta}$ for some fixed $\theta >0$, as $\sigma$ is used
to control the scaling of distance between two data points in the original
version. This way we can control the entropy of the induced probability
distributions, and it is also the very reason we introduce the concept of
perplexity. Finally, because the input kernel is about the probability mass and
should always be positive, we can write it as $\exp(\cdot)$ as the exponential
function is a bijection. In particular, we write the input kernel as
\begin{align}
    p_{j|i} = \frac{\exp(-w(\sigma_i\norm{x_j-x_i}^{\theta}))}{\sum_{k \neq i}\exp(-w(\sigma_i\norm{x_k-x_i}^{\theta}))},
\end{align}
where $w: \mathbb{R}_{\geq 0} \to \mathbb{R}^+$ is a monotone increasing function and $\theta > 0$ is a fixed constant. Naturally, the continuous version of the kernel would be
\begin{align}
    f_{\psi}(x,x') = \exp(-w(\psi(x)\norm{x-x'}^{\theta})),
\end{align}
for some function $\psi: \mathbb{R}^d \to \mathbb{R}^+$. Such expression has several advantages:

1. Since the exponential function is a bijection, we do not lose much generality at all except for how $\sigma$ interact with the output.

2. The form is in direct comparison with the original kernel. As we dive deeper into the computation we can have clear insights about the constraints we need for the input kernel.

3. The exponential function will cancel out the logarithm in the formula of entropy, greatly simplifying the computation and giving us convenience.

4. The form looks natural and aligns with the original concept and motivation of entropy and perplexity.

With the above being said, we can starting adding assumptions to the input
kernel. The most immediate and obvious requirements we can impose will be
\begin{align}
    \lim_{t \to \infty} w(t) = \infty, \qquad \int_0^{\infty} \exp(-w(t^{\theta})) dt =: Z < \infty.
\end{align}
These two are the bare minimum for this problem because apparently we want the normalizing quantity to be finite and $w$ must increase to infinity for a decaying tail. Taking $w(t) = t/2$, $\theta = 2$ and we have the original kernel back. We will start with these basic settings and gradually add more requirements as we proceed through the problem. Also, since the input kernel serves as the weight/probability mass, it is always normalized and we can assume $w(0) = 0$ without loss of generality.
\section{Existence and Uniqueness of \texorpdfstring{$\sigma^*$}{Lg}}
We will try to replicate the results in section 2 of \cite{auffinger-tsne}. Recall that
\begin{align} \label{big_F_formula}
      & F_{\rho,\mu}(x,\sigma) \nonumber                                                                                                                                                                                                                                                           \\
    = & -                                      \int \frac{\exp(-w(\sigma\norm{x-x'}^{\theta}))}{\int \exp(-w(\sigma\norm{x-x'}^{\theta})) d\mu(x')} \log\left(\frac{\exp(-w(\sigma\norm{x-x'}^{\theta}))}{\int \exp(-w(\sigma\norm{x-x'}^{\theta})) d\mu(x')}\right)d\mu(x') + \log \rho \nonumber \\
    = & -\int \frac{w(\sigma\norm{x-x'}^{\theta})\exp(-w(\sigma\norm{x-x'}^{\theta}))}{\int \exp(-w(\sigma\norm{x-x'}^{\theta})) d\mu(x')} d\mu(x') \nonumber                                                                                                                                      \\
      & \qquad \qquad \qquad \qquad - \log \left(\int \exp(-w(\sigma\norm{x-x'}^{\theta}))d\mu(x')\right)  + \log \rho.
\end{align}
We want to show that $F_{\rho,\mu}(x,\sigma) = 0$ has a unique solution $\sigma^* = \sigma_{\rho,\mu}^*(x)$ for all $\rho \in (0,1)$ and $x \in \mathbb{R}^d$. First off, we have $\lim_{\sigma \to 0}F_{\rho,\mu}(x,\sigma) = \log \rho <0$. We will divide the estimation into two parts:
\subsection*{Lower Bound}
Let $x$ be in the support of $\mu$ so we have $f(x)>0$. In this section we aim
to establish a lower bound of $F_{\rho,\mu}(x,\sigma)$ that goes to infinity as
we increase $\sigma$. Since $\lim_{\sigma \to 0}F_{\rho,\mu}(x,\sigma) = \log
    \rho <0$, this will prove the existence of $\sigma^*$. Assume $\mu$ has $C^1$
density $f$ and $f$,$\norm{\nabla f}$ are bounded. Recall
\begin{align}
    Z:=\int_0^{\infty} \exp(-w(t^{\theta})) dt<\infty.
\end{align}
Consider
\begin{align}
      & \int \exp(-w(\sigma\norm{x-x'}^{\theta}))d\mu(x') = \int \exp(-w(\sigma\norm{x-x'}^{\theta})) f(x')dx' \nonumber              \\
    = & \left(\frac{Z}{\sigma^{1/\theta}}\right)^d\int \frac{\exp(-w(\sigma\norm{x-x'}^{\theta}))}{(Z/\sigma^{1/\theta})^d} f(x')dx'.
\end{align}
Because $\lim_{x \to \infty} w(x) = \infty$, the integrand of the above integral converges weakly to $\delta_x f(x')$. This is easy to prove but for the sake of paranoia, I will still do it. Notice that
\begin{align}
           & \int \frac{\exp(-w(\sigma\norm{x-x'}^{\theta}))}{(Z/\sigma^{1/\theta})^d} f(x')dx' \nonumber                  \\
    =      & \frac{1}{Z^d} \int \exp(-w(\norm{\sigma^{1/\theta}(x-x')}^{\theta})) f(x') d\sigma^{1/\theta}(x-x') \nonumber \\
    \equiv & \frac{1}{Z^d} \int \exp(-w(\norm{\tau}^{\theta})) f(x-\tau \sigma^{-1/\theta}) d\tau.
\end{align}
Since $f$ is bounded, $\exp(-w(\norm{\tau}^{\theta})) \sup f$ is integrable. By dominant convergence theorem we have
\begin{align}
      & \lim_{\sigma \to \infty} \frac{1}{Z^d} \int \exp(-w(\norm{\tau}^{\theta})) f(x-\tau \sigma^{-1/\theta}) d\tau \nonumber \\
    = & \frac{1}{Z^d} \int \lim_{\sigma \to \infty} \exp(-w(\norm{\tau}^{\theta})) f(x-\tau \sigma^{-1/\theta}) d\tau \nonumber \\
    = & f(x) \frac{1}{Z^d} \int \exp(-w(\norm{\tau}^{\theta})) d\tau \nonumber                                                  \\
    = & f(x).
\end{align}
There exists some $\epsilon(\sigma) \to 0$ as $\sigma\to \infty$ and a constant $C>0$, that
\begin{align} \label{big_f_lowerbound_1}
    -\log \left(\int \exp(-w(\sigma\norm{x-x'}^{\theta}))d\mu(x')\right) = & -d \log\left(\frac{Z}{\sigma^{1/\theta}}\right) - \log f(x)+ \epsilon(\sigma) \nonumber \\
    \geq                                                                   & C\log \sigma - \log f(x).
\end{align}
Next, since $f$ is bounded, there exists $M>0$ such that $f \leq M$.
\begin{align} \label{big_F_lowerbound_2}
         & \int \frac{w(\sigma\norm{x-x'}^{\theta})\exp(-w(\sigma\norm{x-x'}^{\theta}))}{\int \exp(-w(\sigma\norm{x-x'}^{\theta})) d\mu(x')} d\mu(x') \nonumber                                                           \\
    \leq & M \frac{\int w(\sigma\norm{x-x'}^{\theta})\exp(-w(\sigma\norm{x-x'}^{\theta}))dx'}{\int \exp(-w(\sigma\norm{x-x'}^{\theta}))f(x') dx'} \nonumber                                                               \\
    =    & M \frac{\sigma^{-d/\theta}\int w(\norm{\sigma^{1/\theta}(x-x')}^{\theta})\exp(-w(\norm{\sigma^{1/\theta}(x-x')}^{\theta}))d\sigma^{1/\theta}(x-x')}{ \int \exp(-w(\norm{(x-x')}^{\theta}))f(x') dx'} \nonumber \\
    =    & M \frac{\sigma^{-d/\theta}\int w(\norm{t}^{\theta})\exp(-w(\norm{t}^{\theta}))dt}{ \int \exp(-w(\norm{(x-x')}^{\theta}))f(x') dx'} \nonumber                                                                   \\
    =    & M \frac{\int w(\norm{t}^{\theta})\exp(-w(\norm{t}^{\theta}))dt}{Z^d \int \exp(-w(\norm{(x-x')}^{\theta}))f(x') dx'} \nonumber                                                                                  \\
    \to  & \frac{M}{Z^d f(x)} \int w(\norm{t}^{\theta})\exp(-w(\norm{t}^{\theta}))dt < \infty
\end{align}
if we assume
\begin{align}
    \int w(t^{\theta})\exp(-w(t^{\theta}))dt < \infty.
\end{align}
\gy{Can we get rid of $\theta$ in the integral? If so that would be nice. However, that should not interfere with the rest of the problem because $\theta$ is given and fixed.}
Combine (\ref{big_F_formula}),(\ref{big_f_lowerbound_1}) and (\ref{big_F_lowerbound_2}) and we get
\begin{align} \label{big_F_lowerbound_final}
    F_{\rho,\mu}(x,\sigma) \geq C \log \sigma - \log f(x) + \log \rho.
\end{align}
\subsection*{Monotonicity}
We take derivative of $F_{\rho,\mu}(x,\sigma)$ with respect to $\sigma$ using
(\ref{big_F_formula}). To make the computation clearer, we use simplified
notation in the first several steps:
\begin{align}
    w = w(\sigma\norm{x-x'}^{\theta}); \quad \exp(\cdot) = \exp(-w(\sigma\norm{x-x'}^{\theta})).
\end{align}
Omit $d\mu(x')$ in the integration for cleaner writing, and we have
\begin{align}
      & \frac{\partial}{\partial \sigma} F_{\rho,\mu}(x,\sigma) =-\int \frac{w'\exp(\cdot)}{\int \exp(\cdot)} -\int \frac{w\exp(\cdot)'}{\int \exp(\cdot)} +
    \int \frac{w \exp(\cdot) \left(\int \exp(\cdot)\right)'}{\left(\int \exp(\cdot)\right)^2} - \frac{\left(\int \exp(\cdot)\right)'}{\int \exp(\cdot)} \nonumber                                            \\
    = & -\int \frac{w\exp(\cdot)'}{\int \exp(\cdot)} +
    \int \frac{w \exp(\cdot) \left(\int \exp(\cdot)\right)'}{\left(\int \exp(\cdot)\right)^2} \quad \text{\normalfont (The first and fourth terms cancel.)} \nonumber                                        \\
    = & \int \frac{w\cdot w' \cdot \norm{x-x'}^{\theta} \cdot \exp(\cdot)}{\int \exp(\cdot)}-\frac{\int w \cdot \exp(\cdot) \int w'\cdot \norm{x-x'}^{\theta} \exp(\cdot)}{\left(\int \exp(\cdot)\right)^2}.
\end{align}
We are able to move differentiation inside the integral because of dominant convergence theorem. To show that $\frac{\partial}{\partial \sigma} F_{\rho,\mu}(x,\sigma) \geq 0$, we just need to show
\begin{align} \label{monotone_inequ}
    \int w\cdot w' \cdot \norm{x-x'}^2 \cdot \exp(\cdot) \int \exp(\cdot) \geq \int w \cdot \exp(\cdot) \int w'\cdot \norm{x-x'}^2 \exp(\cdot).
\end{align}
To tackle this inequality, we need the following lemma:
\begin{lemma}[Theorem 7,\cite{liu2000inequ}]
    Let $f(x),g(x),h(x)$ be continuous functions on $[a,b]$ such that
    \begin{align} \label{miracle_condition}
        \left(g(x)-g(y)\right)\left(\frac{f(y)}{h(y)}-\frac{f(x)}{h(x)}\right) \geq 0.
    \end{align}
    Then the inequality
    \begin{align} \label{miracle_inequ}
        \frac{\int_a^b f(x)dx}{\int_a^b h(x)dx} \geq \frac{\int_a^b f(x)g(x)dx}{\int_a^b h(x)g(x)dx}
    \end{align}
    holds. If (\ref{miracle_condition}) reverses, then (\ref{miracle_inequ}) reverses.
\end{lemma}
The lemma can easily be extended to integral over $\mathbb{R}$ if every integral converges, which is our case.
\begin{lemma} \label{miracle_lemma_ext}
    Let $f(x),g(x),h(x)$ be continuous functions $\mathbb{R}^d \to \mathbb{R}^+$ such that for all $x,y \in \mathbb{R}^d$
    \begin{align} \label{miracle_condition_ext}
        \left(g(x)-g(y)\right)\left(\frac{f(y)}{h(y)}-\frac{f(x)}{h(x)}\right) \geq 0.
    \end{align}
    Let $\mu$ be an arbitrary Lebesgue measure and assume all integrals converge. Then the inequality
    \begin{align} \label{miracle_inequ_ext}
        \frac{\int_{\mathbb{R}^d} f(x)d\mu}{\int_{\mathbb{R}^d} h(x)d\mu} \geq \frac{\int_{\mathbb{R}^d} f(x)g(x)d\mu}{\int_{\mathbb{R}^d} h(x)g(x)d\mu}
    \end{align}
    holds. If (\ref{miracle_condition_ext}) reverses, then (\ref{miracle_inequ_ext}) reverses.
\end{lemma}
\begin{proof}
    The proof of this lemma would similar to that in \cite{liu2000inequ}. It suffices to show that
    \begin{align}
        \int_{\mathbb{R}^d} f(x)d\mu \int_{\mathbb{R}^d} h(x)g(x)d\mu \geq \int_{\mathbb{R}^d} h(x)d\mu \int_{\mathbb{R}^d} f(x)g(x)d\mu.
    \end{align}
    The above inequality is equivalent to
    \begin{align}
        \int_{\mathbb{R}^d} f(x)d\mu(x) \int_{\mathbb{R}^d} h(y)g(y)d\mu(y) \geq \int_{\mathbb{R}^d} h(x)d\mu(x) \int_{\mathbb{R}^d} f(y)g(y)d\mu(y).
    \end{align}
    That means we need to show
    \begin{align}
        \mathcal{G}:=\int_{\mathbb{R}^d} \int_{\mathbb{R}^d} g(y)(f(x)h(y)-f(y)h(x))d\mu(x)d\mu(y) \geq 0.
    \end{align}
    Swap $x$ and $y$ in the formula of $\mathcal{G}$ we have an equivalent expression:
    \begin{align}
        \mathcal{G}=\int_{\mathbb{R}^d} \int_{\mathbb{R}^d} g(x)(f(y)h(x)-f(x)h(y))d\mu(x)d\mu(y).
    \end{align}
    Therefore
    \begin{align}
        2\mathcal{G} = & \int_{\mathbb{R}^d} \int_{\mathbb{R}^d} (g(x)-g(y))(f(y)h(x)-f(x)h(y))d\mu(x)d\mu(y) \nonumber                                              \\
        =              & \int_{\mathbb{R}^d} \int_{\mathbb{R}^d} h(x)h(y)\left(g(x)-g(y)\right)\left(\frac{f(y)}{h(y)}-\frac{f(x)}{h(x)}\right)d\mu(x)d\mu(y) \geq 0
    \end{align}
    by the hypothesis of the lemma. This finishes the proof.
\end{proof}
For each $x,y,x' \in \mathbb{R}$ if the equality
\begin{align} \label{monotone_condition}
    (w'(\sigma\norm{x-x'}^{\theta})-w'(\sigma\norm{y-x'}^{\theta}))\left(\frac{1}{w(\sigma\norm{y-x'}^{\theta})}-\frac{1}{w(\sigma\norm{x-x'}^{\theta})}\right) \geq 0
\end{align}
holds, then by letting $f(x) = \exp(\cdot)$, $h(x) = w \cdot \exp(\cdot)$ and $g(x) = w'\cdot \norm{x-x}^2$, we have (\ref{monotone_inequ}) by lemma \ref{miracle_lemma_ext}. Let us take a closer look at the condition. We can assume $\sigma\norm{x-x'}^{\theta}$ is greater than $\sigma\norm{y-x'}^{\theta}$ without loss of generality. Then by monotonicity of $w$, we have $w(\sigma\norm{x-x'}^{\theta})>w(\sigma\norm{x-x'}^{\theta})$. In order for (\ref{monotone_condition}) to be true, we must also have $w'(\sigma\norm{x-x'}^{\theta})\geq w'(\sigma\norm{x-x'}^{\theta})$. This means $w$ has to be a convex function.
\subsection*{Wrap Up}
We know that $\lim_{\sigma \to 0}F_{\rho,\mu}(x,\sigma) = \log \rho <0$ and by
(\ref{big_F_lowerbound_final}) $\lim_{\sigma \to \infty}F_{\rho,\mu}(x,\sigma)
    = \infty$. Moreover, since $F_{\rho,\mu}(x,\sigma)$ is monotone increasing in
$\sigma$, we can conclude there exists a unique $\sigma^* =
    \sigma_{\rho,\mu}^*(x)$ for all $\rho \in (0,1)$ and $x \in \mathbb{R}^d$.
\section{Conclusion}
In this document we have given a specific form to the general kernel and proved
the existence and uniquess of $\sigma_{\rho,\mu}^*(x)$. Let us summarize:

The generalized $t$-SNE has the following kernel
\begin{align}
    p_{j|i} = \frac{\exp(-w(\sigma_i\norm{x_j-x_i}^{\theta}))}{\sum_{k \neq i}\exp(-w(\sigma_i\norm{x_k-x_i}^{\theta}))}.
\end{align}
Here $\sigma_i$ is used to control entropy and $\theta>0$ is a fixed constant. The range of $\theta$ is remained to be determined in the next part of the problem. (We can replace $\sigma_i$ with $\psi: \mathbb{R}^d \to \mathbb{R}^+$ in the continuous version of the kernel.) $w:\mathbb{R}_{\geq 0} \to \mathbb{R}_{\geq 0}$ is a function that satisfies:

1. $w$ is monotone increasing with $\lim_{t \to \infty} w(t) = \infty$.

2. $w$ is a convex function.

3. The following two integrals converge:
\begin{align}
    \int \exp(-w(t^{\theta}))dt < \infty, \qquad \int w(t^{\theta}) \exp(-w(t^{\theta}))dt < \infty.
\end{align}
